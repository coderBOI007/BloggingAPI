Firebase Setup Required

This game needs Firebase Realtime Database for live multiplayer. It's free and takes ~3 mins:

  1. Go to console.firebase.google.com → Create a project
  2. Add a Web App → copy the firebaseConfig object
  3. Left menu → Build → Realtime Database → Create database → Test mode
  4. Open this HTML file in a text editor, find FIREBASE_CONFIG near the top of the <script> and replace it with your config
  5. Save & open in any browser. Share the file with friends — they open it and join with your code!
✦ Entire game is one self-contained HTML file — no server, no install.
✦ Firebase free tier supports 100 concurrent connections (plenty for friends).
✦ For public use, set Realtime Database security rules to restrict access.
